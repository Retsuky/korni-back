# korni-back — документация разработчика

Backend на **Node.js** и **Express**: REST API версии `v1`, PostgreSQL через `pg`, админские маршруты с JWT.

## Запуск

```bash
npm install
npm run dev    # nodemon
# или
npm start      # node src/server.js
```

По умолчанию сервер слушает порт **3020** (см. `src/server.js`, PM2 — `ecosystem.config.js`).

## Переменные окружения

Файл `.env` в корне (не коммитится). Минимальный набор:

| Переменная | Назначение |
|------------|------------|
| `DB_USER`, `DB_HOST`, `DB_NAME`, `DB_PASSWORD`, `DB_PORT` | PostgreSQL (`src/db/db.js`) |
| `JWT_SECRET_ADMIN` | Подпись токена администратора (`src/middleware/tokenAdminController.js`, `src/routes/admin/auth/auth.js`) |

## Маршрутизация

Корневой префикс API: **`/api/v1`**. Подключение модулей — в `src/routes/index.js`.

Публичные префиксы: `/projects`, `/contacts`, `/main`. Админские: `/admin/*` (кроме `/admin/auth`); для остальных требуется заголовок `Authorization: Bearer <token>`.

## Генерация документации по коду (JSDoc)

```bash
npm run docs
```

Описание модулей задаётся в начале каждого файла: блок **`@description`** поддерживает Markdown (таблицы маршрутов, списки). В блоковом комментарии нельзя встречать подряд символы «две звёздочки + слэш», иначе комментарий оборвётся; при перечислении HTTP-кодов пишите, например: **400, 404, 500** с запятыми, а не через слэш сразу после жирного текста.

### Как открыть HTML в браузере

Строка **`docs/jsdoc/index.html`** — это путь от корня проекта, а не то, что вставляют в адресную строку: браузер воспринимает её как поисковый запрос.

**Удобно:** локальный сервер (после `npm run docs`):

```bash
npm run docs:preview
```

В адресной строке открыть **`http://127.0.0.1:4173`** (или ссылку, которую выведет команда).

**Или файл напряму:** через Проводник откройте `docs/jsdoc/index.html` двойным щелчком / «Открыть с помощью» браузера. Либо вставьте **полный** URL вида **`file:///C:/полный/путь/до/docs/jsdoc/index.html`**: три слэша после `file:`, диск и путь через прямые слэши `/`; кириллицу браузер часто сам кодирует при выборе файла через «Открыть файл».
